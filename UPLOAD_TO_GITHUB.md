# FOOTURA PLAYER — GitHub upload

Repository:
https://github.com/emd1818/footura-player

## Upload
1. Open the repository.
2. Click Add file → Upload files.
3. Drag the CONTENTS of this package into the upload area, preserving folders.
4. Commit directly to the `main` branch (or the repository's default branch).
5. Open Actions and confirm `FOOTURA Football Trials Daily Update` appears.

## Important
The workflow is scheduled once every 24 hours.
It can also be started manually from Actions → FOOTURA Football Trials Daily Update → Run workflow.

No Lovable connection is required.

The workflow uses public web discovery, preserves the source URL, keeps uncertain discoveries in REVIEW, and writes the database file back to the repository.
