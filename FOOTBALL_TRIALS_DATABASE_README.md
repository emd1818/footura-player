# FOOTURA PLAYER — ФУТБОЛНИ ПРОБИ / Daily database

Това е нова, чиста база за футболни проби. Не използва фалшивите записи от Lovable.

## Начална база
Включени са реални, проверени чрез публични източници записи от България, Испания и Китай, плюс структура за разширяване към всички 7 езика.

## Автоматично обновяване
`crawler/crawl_trials.py` извършва discovery всеки ден и обновява `data/football_trials.json`.

За реален 24-часов production режим пакетът съдържа GitHub Actions workflow, който се стартира ежедневно в 02:15 UTC.

ВАЖНО: Google News RSS е discovery слой. Новооткрити URL-и се поставят `REVIEW`; те не стават автоматично `ACTIVE` само защото са намерени в search резултат. За production трябва да има source-verification стъпка преди автоматично публикуване.

## Интеграция с FOOTURA PLAYER
Frontend-ът може да зарежда `data/football_trials.json`. Съществуващите модули не се променят.
